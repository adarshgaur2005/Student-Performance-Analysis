# Student Performance Analysis Using Python

## About the Project
This project analyzes student performance in Mathematics, Reading, and Writing using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Average marks by subject
- Performance comparison by gender
- Effect of test preparation
- Top-performing students
- Correlation between subject scores

## Conclusion
This project helped me practice data analysis and visualization using Python libraries.
